# Provenance of the input data

Hashes are of the files as used in the reported measurements, so a reader
can tell whether a source has changed since.

## Instructions for Authors

The guideline document is the **Instructions for Authors of Biophysics and
Physicobiology (BPPB)**, version marked **"Revised 21 August, 2026"**,
retrieved on 21 August 2026 from the journal website. It is redistributed here
with the permission of the Editor-in-Chief, on the condition that the version
date is stated, which is the purpose of this note. The journal publishes the
Instructions as a web page and as a PDF, and revises them from time to time,
so the version date rather than the URL identifies what was measured.

`bppb_instructions_clean.txt` is the file the models were given: the complete
document converted to plain text by `harness/make_clean_guidelines.py`, 5,092
words, ending with the version line. An earlier round of measurements used a
copy that cleaning had truncated after the section on reprints, dropping the
sections on Errata, Corrigenda, Addenda, Retractions and Expression of Concern
together with the version line. Every measurement reported in the manuscript
was re-run against the complete text, and the conversion script now exits with
a non-zero status if any required section or the version line is missing. The
document as retrieved is included as `bppb_instructions.txt` and
`bppb_instructions.html` so the conversion can be checked.
