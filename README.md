# A benchmark of locally hosted language models for journal editorial work

Manuscripts under review are confidential, so a journal that wants to use a
language model on them has to run it on hardware it controls. This repository
holds a benchmark that measures how far locally hosted, open-weight models get
on that work, and everything needed to reproduce the measurements.

**20 models from 3.3 to 81 GB, 8 editorial tasks, 313 measured conditions on a
single compact desktop workstation, plus 44 measurements across two nodes.**

## What the measurements show

- Guideline compliance reaches a useful level: the strongest model detects
  **36 of 40** seeded violations and occupies **81 GB**, while
  `qwen3.8:27b` at 17 GB detects **33**.
- **No consistent monotonic association between weight size and score** on any of
  the 8 tasks, across the best configuration tested for each model. Spearman rank
  correlation over the 10 scored measures runs from -0.19 to +0.13; within one
  model family the 65 GB member scores below its 13 GB sibling.
- A **deterministic checker** — regular expressions and arithmetic, no model —
  finds **31 of the same 40** in under 0.1 s with 0 false positives. The
  union of its detections with the strongest model's covers **40 of 40**, so the
  marginal contribution of the language model is **9** violations rather than 36.
  The two layers were measured separately; no integrated pipeline was run.
- Peer-review support recovers **6 of 12** points that real reviewers raised on
  one preprint. Whether presenting such output improves a human review was not
  measured.
- **Prompt structure moved most models, and not always upward.** Of the
  14 models measured under both prompt forms at matched reasoning effort,
  9 detect more under a checklist, 2 detect fewer, and 3 detect nothing under
  either. Neither quantization step within one model family helped, and both cost
  memory.

## Layout

```
paper/manuscript.md         the manuscript
paper/figures/              figures 1-8 and the graphical abstract, 300 dpi
data/                       guidelines, 5 manuscripts with the verified seeded
                            defects, ground truth, figure stimuli, reviews
data/PROVENANCE.md          source, size and SHA-256 of every third-party input
results/                    313 conditions + summary CSVs + twonode/matrix.json
harness/                    runners, grader, ground-truth verifiers, the
                            deterministic baseline, figure generation
docs/worklog.md             chronological working log, including predictions that
                            proved wrong and the corrections that followed
docs/pitfalls.md            measurement traps found the hard way
docs/03-results.md          every per-task table, regenerated by make_report.py
```

## Reproducing

Every tabulated number comes from `results/` via `harness/make_report.py` and
`harness/make_paper_figures.py`; none is transcribed by hand. `harness/check_claims.py`
recomputes the claims the manuscript makes and fails if any disagrees, and
`harness/check_manuscript.py` checks its limits, references and figure wiring. This
README is generated the same way, by `harness/make_public_release.py`.

Ground truth passed 52 independent arithmetic checks before any model was scored —
which is how the *compliant control manuscript* was found not to be compliant.

Inference used ollama. Note that two runtime versions were in use and the
top-scoring model ran on the newer one; this is a confound we did not remove, and
it is stated in the manuscript's limitations rather than hidden.
